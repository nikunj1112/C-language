# 📘 Grade Calculator (C Program)

This project is a simple **Grade Calculator** written in **C language** that calculates:

✔ Total Marks  
✔ Percentage  
✔ Grade (A, B, C, D, F)

---

## 🧾 **Features**

- Accepts number of subjects from user
- Takes marks out of 100 for each subject
- Calculates:
  - Total Marks
  - Percentage
  - Grade based on percentage
- Displays final result

---

## 📌 **Grade Criteria**

| Percentage | Grade |
|-----------|--------|
| 90% & above | A |
| 80% - 89% | B |
| 70% - 79% | C |
| 60% - 69% | D |
| Below 60% | F |

---

## 🧮 **How It Works**

1. User enters number of subjects  
2. User enters marks for each subject (out of 100)  
3. Program calculates total & percentage  
4. Then assigns a grade based on percentage
