## ✅ Q.1 Negative Elements in 1D Array

### 📝 Problem Description
Develop a program that finds all the **negative elements** from a given **1D array**.

### 📥 Input Example
```
Array Size: 5
Elements: 2, -4, 1, -3, -5
```

### 📤 Expected Output

Negative elements from the array: -4 -3 -5

## ✅ Q.3 Transpose of 2D Array

### 📝 Problem Description

Elements: 2 4 1
